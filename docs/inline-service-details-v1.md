# 下方详情纸页 V1

用户确认先实现展现效果，再逐张铺内容。首屏吊牌、手绘卡片保持原有结构；内部服务卡片点击后展开首屏下方的详情区，平滑滚动到对应标题，不使用弹窗、遮罩或强制整屏吸附。

## 入口

- 知识付费：求职规划、定制成长、全程陪跑。
- 项目合作：项目咨询、方案交付。
- 定制服务：定制化 WeChat Bot。
- 安静：团队介绍。
- 自我介绍、开源作品、Happy Journey 仍跳转现有外部网站。

可展开的内部卡片采用暗金细框和手形光标，移动端显示向下箭头；外链卡片保持外跳箭头。

## 纸页结构

纸页使用原有米白纸纹，顶部展示所属业务与卡片标题，附「↑ 返回选服务」。电脑双列、手机单列，预留适用情况、具体做法、交付物、案例四个区域。正文暂留空白纸线和整理提示，不编造案例、交付承诺或价格。底部提供需求沟通与复制微信 daxingbomei 的入口。

点击返回滚回首屏，并将焦点交回来源卡片；再次选择其他卡片时更新同一纸页。尊重减少动态设置，详情可自然滚动浏览。后续按服务逐项完善内容。

## 验证

已验证项目咨询展开、返回、切换方案交付、微信复制状态、手机求职规划展开、单列排版、无横向溢出、无控制台错误。
