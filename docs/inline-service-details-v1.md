# 下方详情页 V1

用户确认先实现展现效果，再逐张铺内容。首屏吊牌、手绘卡片保持原有结构；内部服务卡片点击后展开首屏下方的详情区，平滑滚动到第二屏，不使用弹窗、遮罩或强制整屏吸附。

## 入口

- 知识付费：求职规划、定制成长、全程陪跑。
- 项目合作：项目咨询、方案交付。
- 定制服务：定制化 WeChat Bot。
- 安静：团队介绍。
- 自我介绍、开源作品、Happy Journey 仍跳转现有外部网站。

可展开的内部卡片采用暗金细框和手形光标，移动端显示向下箭头；外链卡片保持外跳箭头。

## 第二屏结构

按最新反馈，第二屏与首屏共用同一层固定水纹背景及大理石备用底色，高度限定为一个视口。在背景上放置一张接近整屏的空白大纸片，复用原卡牌的棉纸纹理、浅色纸边与层叠阴影，四周适量留白。移除「返回选服务」，纸片内不放标题、正文、占位提示或按钮，后续逐项维护详情。

再次选择其他卡片时复用同一详情页，通过 data-service 和无障碍名称保留所选服务身份。向上滚动即可回到首屏，尊重减少动态设置。

## 验证

构建检查与电脑、手机浏览器检查：详情区保持一屏，纸片完整可见，无横向溢出；原卡牌选择与滚动展开保留。
